# Reliable task completion guides

Six substantial guides are bundled in Settings → Plugins. Search by the names below. They use existing tools and permissions; they do not add new executable backends. Automatic retrieval keeps the complete task/check/stop recipe within the existing small-context budget. The longer reference is available through read_workflow when needed.

- Reliable multi-source web research: Research a question using actual source reads, a claim ledger, independent evidence where available, and an honest answer that distinguishes verified facts from search leads.
- Readable screenshots with verified vision and real attachments: Capture a requested page or region, preserve a real image receipt, analyze only legible pixels and deliver the actual screenshot without substituting a webpage URL or a remembered example.
- Complete research and screenshot requests together: Finish mixed tasks that require web search, multiple source reads, saved screenshots and visual explanation without stopping after the first successful image or reporting a plan as completion.
- Long files in checked chunks without repeated content: Create or extend large requested files using bounded append operations, current hashes, exact size contracts and saved checkpoints while preserving source bytes and the finite working context.
- Debug the exact file, verify the repair and save it: Reproduce a reported file defect, inspect precise source ranges, repair only the demonstrated problem and verify the saved revision without confusing syntax checks with executed behavioral tests.
- Resume stalled tasks from evidence and keep models ready: Recover multi-step work from real receipts, distinguish failed actions from uncertain outcomes and preserve the selected model instead of repeatedly resetting tools, tasks or inference state.

The guides cover real evidence and attachments, readable captures, combined deliverables, chunked file completion, exact-source repairs and resumable work. They do not guarantee factual accuracy, unlimited context, every website being accessible or a fixed speed on every GPU.
