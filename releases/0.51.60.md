# Arc 0.51.60 — File History, browser tools and guided work

Arc 0.51.60 is a cumulative Windows x64 development release covering **0.51.53–0.51.60**, following the previously published 0.51.52 installer. It adds recoverable file history, a browser task library, 60 guided work areas, Steam research, Twitch alerts, and more precise coding repairs.

**Download `Arc-Setup-0.51.60.exe` from Assets below.** Models remain separate downloads. Normal updates preserve separately stored models, conversations, settings and personal guides. Finish active work before updating.

## Remember and recover your work

**Created Files → File History** now provides a searchable local backup library. Arc records saved files and revisions with their filename, date, file type, a text excerpt and the creation instructions when available. Ask “Find the PHP page we created” or “Restore my lost notes.” Arc can search earlier work, inspect verified source and return an exact restored file in chat.

- New Created Files saves and appends, verified local-PC file saves, local PHP project files and generated images are backed up automatically. Existing Created Files are imported after startup; a manual backup button is also available.
- Backups are independent of the working copy and conversation. Deleting either does not delete the backup. Restoration verifies SHA-256 and creates a numbered copy when the name is already taken.
- Identical content is stored once. The initial limit is **10 GiB of unique file bytes and 50,000 version records**, with visible warnings and manual removal. Older versions are not automatically erased.
- Search is local and requires no extra model, embedding download or VRAM. It uses metadata and the first 8,000 characters of text; full source can be read in excerpts.

This is recovery on the same PC, not an off-device backup. It cannot recover files deleted before their first backup, survive loss of the disk or Arc application data, or automatically rebuild an entire multi-file project. Remote SSH backups retain their existing separate behavior. [File History guide](https://github.com/pixelgraple/arc-desktop/blob/v0.51.60/releases/0.51.60/FILE_HISTORY.md)

## Browser tasks you can find and use

**Settings → Plugins → Browser tasks** adds **120 detailed workflows across 12 groups**, each with an editable example, a procedure, evidence checks and recovery instructions. They cover tabs, navigation, page elements, copying, screenshots, vision discussion, forms, research, structured data and reporting.

Four new controls extend the existing browser engine:

- Locate rendered text and its surrounding context.
- Inspect a selected region for text, headings, links, labeled controls or table rows.
- Highlight a region with a passive blue outline; Escape or ten seconds removes it.
- Scroll a page or container, or bring an observed target into view.

These are 120 task guides and four new controls, not 120 separate execution engines. Browser permissions, sign-ins and human CAPTCHA handling still apply. Small-context responses retain complete records and continuation positions. Canvas, frame and shadow-root content can still require the existing screenshot/vision paths.

## Sixty work areas and seven practical utilities

**Settings → Plugins → Work Areas** adds 60 searchable areas for coding, research, data, writing, learning, planning, platforms, voice/vision and operations. Each provides a detailed guide, six stages with acceptance checks, prerequisites, failure handling, a concrete deliverable and an editable prompt.

Seven utilities help the model organize and verify work: a work-area planner, checkpoint audit, research-evidence audit, weighted comparison, measured-value summary, unit converter, and text-length/repetition review. Requested exports go through Created Files. These utilities calculate or check structured evidence; they do not establish factual truth, literary quality or successful remote actions by themselves. Existing personal guides and off switches are preserved.

## More precise coding repairs

Arc can read exact line ranges, append to an existing code file and replace only the faulty lines while preserving surrounding content and originals. Current source hashes and observed ranges guard against stale or guessed edits. The local PHP workspace also gains append and inclusive line replacement.

Requests such as “test/debug this file and correct errors” route through read, check, repair and recheck. Supported syntax checks and existing JavaScript assertions run against corrected revisions when enabled. Check-only requests do not authorize edits; syntax-only checks do not execute JavaScript. Missing checks cannot be reported as passed. Existing sandbox and server-publishing boundaries remain in place.

## Steam, platform research and Twitch

- **Steam game research:** search for a game and retrieve current player counts, region-specific prices, review totals, metadata, global achievement percentages and news. Results include source links and retrieval times. No account or API key is needed for these public tools. SteamDB links are provided as references; historical SteamDB statistics are not scraped or represented as available.
- **150 platform guides:** 30 each for eBay, Steam, YouTube, X/Twitter and Twitch, with examples, collection instructions, source checks and failure handling. Find them under **Settings → Plugins → Platform research guides**. Account and platform restrictions remain in effect.
- **Twitch alerts:** a dedicated settings page supports channel selection, live-stream alerts while minimized, optional stream-ended/category alerts, game filters, quiet hours, device-voice announcements and recent activity. It runs without model inference. Setup requires a Twitch Public developer application Client ID and user sign-in; instructions are included. Automated checks passed, but real account-connected notification delivery still awaits that setup. [Twitch setup guide](https://github.com/pixelgraple/arc-desktop/blob/v0.51.60/releases/0.51.60/TWITCH_ALERTS.md)

Existing **Hey Arc / Arc Mini**, **Show Arc screen and audio conversation**, **Watch with Arc for YouTube**, Agent Reach, up to 20 requested screenshots, Ultra continuation and model residency remain available. No model weights or inference backends are changed by these releases.

## Validation and practical limits

- For 0.51.60, **267 regression tests**, **19 focused recovery tests**, and the plugin-upgrade check passed. These overlapping runs are not a combined unique-test total.
- The real File History UI passed search, preview, deleted-file recovery, collision preservation, Explorer handoff, version filtering, keyboard closing and desktop/narrow-layout checks using isolated real file storage.
- TypeScript, production build and Windows packaging passed. The packaged app recovered deleted files byte-for-byte, searched after restart, preserved originals and loaded its tool registry and guide.
- Earlier component runs recorded **470 browser regression tests** for 0.51.59 and **231 Work Areas regression tests** for 0.51.58. Counts describe those runs, not a rerun of every app test against 0.51.60.
- No new live-model speed or accuracy benchmark is claimed. The latest work did not rerun the entire application suite or establish that the two previously reported memory-budget failures are resolved. External platform access, authenticated eBay sold-item results and real Twitch account delivery retain their documented limits.
- Local models can still make mistakes. Guides and continuation do not remove context limits or guarantee task completion. This is a Windows x64 release; no macOS installer or Android APK is attached.
