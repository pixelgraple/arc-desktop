# Arc 0.51.85 — Review before replying

High can take a second look at a final draft. Ultra can check it again. Arc compares
the request, constraints and recorded evidence, then makes one bounded correction
when a substantive gap is identified. A short outcome checklist also accompanies
eligible parent work calls.

The thinking-level menu includes **Review before replying**, on by default for
High/Ultra. Instant, Medium and voice retain their existing response paths. Brief
progress and review counters distinguish checks, corrections, skipped reviews
and unavailable checks.

The selected model handles reviews serially with no tool execution. Existing
permissions, evidence/completion gates, CPU code review and sandbox boundaries
remain authoritative. Extra calls cost time and tokens; they do not enlarge the
context window or guarantee a correct answer. Full details: `ANSWER_REVIEW.md`.
