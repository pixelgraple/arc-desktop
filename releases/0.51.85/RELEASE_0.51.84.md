# Arc 0.51.84 — Music feature removal

Removed Arc's standalone YouTube Music player, saved-playlist panel, and voice/text playback commands. The music-only stream resolver, local playback services, and packaged resolver wheel are no longer included.

YouTube search, captions, transcripts, video research, and screen/audio context remain available. Existing playlist metadata on this PC is left untouched and is no longer read by Arc. TwinYou Music is a separate project and is unchanged.
